# AI使用与验证记录

## 工具与责任

本轮使用Codex协助阅读题目、审查现有项目、实现与测试；运行时使用DeepSeek编排任务与解释证据；扶摇提供金融数据。此前项目文档声明使用Claude Code，但本轮没有独立核验该历史过程。

AI参与实现不等于产品具有运行时AI能力。本版本真实调用模型生成结构化研究计划，再按白名单工具执行；计算、阈值、时点与质量判断由确定性代码负责。

候选人的已确认动作：提供原题、调整目标、授权实施、提供扶摇与DeepSeek凭据，要求克制的页面设计。以下修正与验证由本轮编码代理执行；不把代理操作写成候选人已亲自复核。

## 实际修正

1. 原静态构建强制SAMPLE：改为真实数据Snapshot和在线Worker，构造数据只留在旧回归测试。
2. 原估值接口误用于指数：官方文档仅支持个股，停止输出指数估值结论，显示缺失。
3. 原页面没有研究问题入口：新增指数、交易日区间、问题输入及模型任务计划。
4. 原证据只有维度级接口追溯：新增结论与证据ID、逐项原始输入、跨指标依赖与请求标识。
5. 原置信度奖励维度方向同向：改为质量评估，不把可靠背离当作低可信的直接原因。
6. 原切换条件可能与分类逻辑不一致：共用确定性标准，验证每个已满足条件对应当前维度状态。
7. 日历缺失不能回退当前时间伪装交易日；盘中日线不能叫完成收盘；日历覆盖过期不能把未知日期断言为非交易日。
8. 模型错误或无效证据引用不採用；模型异常显示规则降级，保存回放显示REPLAY。
9. 发布快照去掉无关完整个股报价与名称，仅保留分析所需字段。

## 验证方式与局限

用真实Key验证日历、指数历史/快照、成分、个股快照、股票池、行业目录。对收益、均线、宽度、情绪计数与来源检查编写自动化断言。通过浏览器实际操作输入、计划、结果、证据及二级研究；公网验证结果另见测试说明。

自然语言语义仍需要人工复核：结构校验、来源约束和敏感词拦截不能保证解释完全无误。本项目保留可见证据、缺失项和模型状态，供评委核验。
