## 正式链路断言

- 所选区间使用正确的N+1个收盘端点；改变指数与区间实际改变结果。
- 核心证据有字段、来源、时点、单位、口径与原始输入，结论引用可解析。
- 宽度缺失、成分失败、过期数据不补零、不当作完整市场。
- 行情快照与日线冲突停止正常结构归纳，并降低置信度。
- 股票池分页不完整停止正常情绪结论。
- 指数估值、事件未接入不生成伪造事实。
- 状态切换标准与状态分类一致。
- 四类继续研究有实际结果；历史证据不超出当时截点。
- 非交易日、盘中日线、预测与交易建议边界被明确处理。
- LIVE失败明确切换真实Snapshot；模型缺失明确RULE。
- 不存在的证据ID导致拒绝模型解释；篡改签名计划不能注入任意工具。
- 日历失败不回退服务器时间生成交易日。
- API非法JSON被拒绝，保存案例标注REPLAY。

## 评委可复现的边界操作

1. 输入「预测明日涨跌」：显示边界说明，不生成研究结果；可选择改为状态研究。
2. 输入「推荐仓位」：不提供操作建议。
3. 选择Snapshot：日期固定，明确非实时；仍可实时调用模型。
4. 点击案例回放：AI状态REPLAY，数据SNAPSHOT，本次不调用外部接口。
5. 数据故障在自动化测试使用注入fetcher模拟，不在公开页面提供会修改真实服务的调试按钮。

新增4项调用保护测试：相同请求合并及缓存隔离、并发限制与失败释放、实例日额度与次日重置、缓存过期重算。当前45项通过。
