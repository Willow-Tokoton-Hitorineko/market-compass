# 120秒演示脚本

- 0—15秒：打开公网URL，说明要核验「指数结构和市场参与度是否一致」。选上证综指、近20个交易日，点击开始研究。
- 15—35秒：展示Research Plan、数据来源、实际执行状态和缺失维度。说明模型负责组织研究，计算由代码执行。
- 35—55秒：读核心结论与主要矛盾，核对截至日、最近交易日、LIVE/SNAPSHOT、完整度与置信度。缺失估值和事件源不隐藏。
- 55—80秒：点击结论，展开一条区间收益或宽度证据，展示原始字段、时点、口径、原始输入与计算公式。
- 80—100秒：查看判断改变条件：当前状态、观察变量、阈值与目标状态；说明它描述复盘标准，不是明日预测。
- 100—115秒：点击行业或历史阶段，展示继承同区间、同截至日的二级结果及证据。
- 115—120秒：指出案例回放与显式降级能力。结束。

备用：接口失败时展示清楚的错误与真实Snapshot切换，再走证据和继续研究。不能把回放说成实时AI。
