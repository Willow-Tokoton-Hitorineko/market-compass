## 两分钟体验

1. 保持上证综指、近20个交易日、LIVE，点击“开始研究”。问题为“指数的价格结构与市场参与度是否一致？哪些证据会改变判断？”
2. 查看研究计划中的任务、数据来源、可调用能力和执行状态。
3. 查看市场状态、主要矛盾、置信度及依据；点击核心结论打开证据窗口，核验时点、单位、口径、原始字段和计算输入。
4. 查看“判断改变的条件”，再点击风格、行业、风险变量、历史阶段，继续核验对应证据。

若外部服务不可用，页面明确显示失败与Snapshot切换或规则降级。也可点击右上“案例回放”查看保存的真实研究案例；回放无需外部调用，明确显示REPLAY，不冒充实时生成。

## 实现与产品选择

产品服务于A股市场复盘与研究。模型识别问题并排序取数任务，组织证据解释与后续问题；均线、区间收益、市场宽度、阈值与质量置信度由确定性代码计算。任务计划不是内部思维链。结果区分FACT、SYNTHESIS、UNCERTAINTY；不提供涨跌预测、收益承诺、仓位或直接买卖建议。

保留七维研究框架，当前行情结构、宽度、风格、交易活跃度及情绪有实际证据，估值与事件源未接入。宽度为当前宽基成分并集横截面，行业为8个观察样本；不宣传全市场或全行业覆盖。置信度是证据质量档位，不是收益概率。能力与边界详见源码/README.md。
